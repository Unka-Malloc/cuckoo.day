    What body text looks like now that variable fonts have landed

    Kerning Weekly · Oct 15

    Every major browser now supports variable fonts. One file covers every weight from hairline to black, so body text can tune its strokes to each screen and size without loading several files.

    The biggest change, the author argues, is at small sizes: notes and captions can be a touch bolder and more open, and read better than shrunken body text.

    Good typography is invisible: readers remember the words, not the typeface.
