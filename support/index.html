Support

Getting started with Cuckoo for Mac. Requires macOS 14 or later.

1 · Connect your model

Follow the first-issue guide, or open Settings → Model. Choose a provider, enter its API key, load and select a model, then choose Connect. Cuckoo verifies the selected model before saving the key in your keychain. Apple or Google account sign-in is optional.

2 · Add sources (optional)

Connect GitHub and Gmail in Settings. On the Mac you can also choose Apple Mail accounts and folders. Choose which repositories and mailboxes to include.

3 · Read

A new edition is written at 06:00 and 18:00 when the app is open, or whenever you choose Refresh. Click or tap a story to read it in full, give feedback, or ask the assistant for help.

Sharing between devices

In Settings, set the storage location to iCloud Drive on each device. Model keys and source connections are set up separately on each device.

If an edition fails

The previous edition stays readable. Check that your provider key is valid and your network is available, then choose Refresh.

帮助与支持

在 Mac 上开始使用晨昏报，需要 macOS 14 或更新版本。

一 · 连接模型

按创刊号引导操作，或打开「设置 → 模型」。选择供应商、输入 API 密钥、获取并选择模型，再点「连接」。验证通过后，密钥才会保存到钥匙串。Apple 或 Google 账号登录可以跳过。

二 · 添加来源（可选）

在设置中连接 GitHub 和 Gmail。在 Mac 上还可以选择 Apple 邮件账户和文件夹，并挑选要包含的仓库和邮箱。

三 · 阅读

App 打开时，每天 06:00 和 18:00 各写一期；你也可以随时点「刷新」。点开一篇报道即可阅读全文、留下反馈，或让助手帮忙。

在设备之间共享

在每台设备的设置中将存储位置设为 iCloud Drive。模型密钥和来源连接需要在每台设备上分别设置。

生成失败时

上一期报纸会保留可读。请检查供应商密钥是否有效、网络是否可用，然后点「刷新」。
